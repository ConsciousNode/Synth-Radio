# Synth-Radio
An infinite offline radio station!

**Play it:** https://consciousnode.github.io/Synth-Radio/

146 procedurally generated channels: amber CRT dial, genre profiles, Euclidean rhythms, physical-modelling voices, FDN and plate reverbs, a Pirate Radio switch, binaural drone. Every channel is generated live from a seed, so it never runs out.

One HTML file. Zero dependencies. Works offline. Open `index.html` in any modern browser, or use the Pages link.

**v13 (2026-10-13):** diatonic harmony fix. Chords are built from each channel's own scale. Out-of-key notes dropped from 40% to 0.4%, semitone clashes from 1.6% to 0.5% (146 channels × 6 seeds).
